# Scopelio v0.3.0 — Text backups

- Export all filters to a local UTF-8 `.txt`, preserving names, terms, colors and matching options.
- Import Scopelio backups or plain text with one term per line.
- Preview filters and term counts before adding to or replacing the current list.
- Invalid files, unsupported versions and over-limit imports leave current filters intact.
- English and Brazilian Portuguese support; no new browser permissions.

Click **⇅** beside **Your filters** to open Import or export filters. Existing filters and preferences are preserved when updating the extension.

Download and extract `scopelio-0.3.0.zip`, enable Developer mode at `chrome://extensions` or `edge://extensions`, then Load unpacked. For an existing unpacked installation, update the files in the same folder, reload the extension and reload your web pages. Chrome/Edge 120+; store submission remains pending.

## Português

Agora você pode exportar e importar filtros por `.txt`. Clique em **⇅** ao lado de **Seus filtros**. A prévia permite adicionar ou substituir a lista; nomes, termos, cores e opções são preservados. Também aceita texto simples com um termo por linha. Sem novas permissões ou envio de dados a servidores.
