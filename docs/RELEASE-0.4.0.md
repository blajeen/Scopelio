# Scopelio v0.4.0 — A clearer view

- Larger, centered popup donut with a stable page total in its center.
- Filter names, counts and percentages in full-width rows below the chart.
- Hover and keyboard previews display outside the ring; the center never switches to filter details.
- Cleaner Orbit reading mode: just the ring, total and small drag handle. Filter details and controls appear on interaction.
- Reused SVG arcs on live updates, preserved keyboard focus, and animation-frame scheduling for drag and resize.
- Reuse of matching results for style-only changes that leave analyzed text unchanged; new counts commit together after each scan.
- Existing filters, .txt backups, language choices, site permissions and saved Orbit position are preserved.

Download and extract `scopelio-0.4.0.zip`, enable Developer mode at `chrome://extensions` or `edge://extensions`, then Load unpacked. To update an existing unpacked installation, replace the files in the same folder, reload the extension and reload open web pages. Chrome/Edge 120+; store submission remains pending.

## Português

Donut maior e centralizado, total fixo no centro e filtros em linhas abaixo. No Orbit, os detalhes e controles ficam ocultos durante a leitura e aparecem ao interagir.
