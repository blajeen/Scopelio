# Scopelio v0.2.0 — Orbit

Keep your insights in view with **Scopelio Orbit**, an optional floating donut on the page.

- No panel background; the transparent center and unused areas let website clicks pass through.
- Adjustable opacity (20–100%), with full visibility during interaction.
- Drag to move, or use arrow keys on the handle; position persists locally and adapts to window resizing.
- Select a colored arc to focus a filter and navigate its occurrences.
- Live updates while the extension popup is closed; close and reset controls built in.
- Refined Scopelio identity with calibration rings, an iris detail and a consistent orbital visual motif.
- A more compact popup with a side-by-side donut and legend; hover or focus a filter for an interactive preview in both charts.
- English and Brazilian Portuguese, with English as the default.

## Use

Enable **Show floating donut** below the popup chart. Enable **Always on this site** for automatic activation on future visits. Existing filters and settings are preserved. If updating an unpacked extension, reload it in `chrome://extensions` or `edge://extensions`, then reload your web pages.

Download and extract `scopelio-0.2.0.zip`, enable Developer mode in the browser's extensions page, choose Load unpacked, and select the extracted folder. Chrome/Edge 120+ required. Store submission remains pending.
