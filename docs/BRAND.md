# Scopelio icon

The icon was created with OpenAI's built-in image generation tool on November 4, 2026. The original generated PNG is preserved in `assets/icon-source.png`; `assets/icon.png` is the 512px documentation version. Production extension icons are resized to 16, 32, 48 and 128px in `extension/icons/`, preserving transparency. The generated icon is used in the browser toolbar, extension management screen and popup header.

The ring subtly suggests a lens for finding patterns in text. Minimal liquid glass aesthetic, softly translucent material, controlled dimensionality, crisp silhouette, generous open circular center. Front-facing perfectly circular design, no perspective tilt. Strong legibility at 16px as well as 128px. Ring fills 84 percent of square canvas with safe margins. Transparent background outside AND inside the ring. No square tile, no typography, no letters, no extra objects, no tiny details, no drop shadow outside the symbol, no watermark. Deliver a single high resolution square icon.
